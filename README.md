# makeForms

Microsoft Forms 편집 화면을 조작해 AI가 생성한 퀴즈 문제를 자동으로 채워 넣는 브라우저 확장 프로그램입니다. Chrome은 물론 **Edge에서도 동일한 방법으로 설치하고 그대로 사용할 수 있습니다** (Manifest V3 표준 API만 사용하는 Chromium 기반 확장이라 Edge 전용 수정이 필요 없습니다).

## 동작 방식

1. `forms.office.com`에서 편집 중인 폼을 엽니다.
2. 확장 프로그램 팝업에서 AI 생성(주제/파일/개수/난이도) 또는 CSV 파일 중 하나로 문항을 준비하고 버튼을 누릅니다.
3. AI 모드라면 백그라운드 서비스 워커가 Google Gemini API(`gemini-3.5-flash`)로 문제와 폼 제목(JSON)을 생성합니다. 파일을 첨부한 경우 파일 내용을 근거로 문제를 만듭니다. CSV 모드라면 이 단계를 건너뛰고 팝업에서 CSV를 직접 파싱합니다.
4. 팝업이 자동으로 닫히고, 페이지의 MAIN world에서 실행되는 `page.js`가 현재 열려 있는 Forms 편집 화면의 DOM을 조작해 폼 제목 입력 → "새 질문 추가" → 제목/보기 입력 → (퀴즈 모드면) 정답 표시 → 필수 설정까지 자동으로 수행합니다. (격리 월드에서 실행하면 텍스트 입력이 Forms 내부 상태에 반영되지 않아 MAIN world를 사용합니다. `content.js`는 background와 `page.js` 사이의 메시지만 중계합니다.)

Gemini 모델은 Google이 예고 없이 구버전을 폐기하는 경우가 있습니다(`gemini-2.5-flash` → 404 사례 있었음). 모델이 다시 404를 내면 `extension/background.js` 상단의 `MODEL` 상수만 최신 모델 ID로 바꾸면 됩니다.

Microsoft Forms는 폼 문제를 프로그래밍 방식으로 생성하는 공개 API를 제공하지 않기 때문에(Graph API의 Forms 관련 엔드포인트는 관리자 설정 조회/변경용뿐), 브라우저 DOM 자동화 방식을 사용합니다.

## 설치 방법 (하나씩 따라 하기)

이 확장 프로그램은 Chrome 웹 스토어에 올라와 있지 않고, 저장소 코드를 직접 브라우저에 불러와서(개발자 모드) 사용합니다. Chrome과 Edge 모두 동일한 방법으로 설치할 수 있습니다.

### 1단계. 이 저장소를 내 컴퓨터에 준비하기

이미 이 폴더를 가지고 계신다면(예: git clone으로 받으셨다면) 이 단계는 건너뛰어도 됩니다. `extension` 폴더가 어디 있는지만 기억해두세요.

### 2단계. 확장 프로그램 관리 화면 열기

1. 브라우저 주소창에 `chrome://extensions` 를 입력하고 엔터 (Edge라면 `edge://extensions`)
2. 화면 오른쪽 위에 있는 **"개발자 모드"** 토글 스위치를 켭니다. 켜면 "압축해제된 확장 프로그램을 로드합니다" 같은 버튼들이 새로 나타납니다.

### 3단계. 확장 프로그램 불러오기

1. 방금 나타난 **"압축해제된 확장 프로그램을 로드합니다"** 버튼 클릭
2. 폴더 선택 창이 뜨면 이 저장소 안의 **`extension`** 폴더(하위 폴더 아님, `extension` 폴더 자체)를 선택
3. 확장 목록에 "makeForms - AI 문제 자동 생성"이 나타나면 성공입니다. 브라우저 툴바(주소창 오른쪽)에 아이콘이 안 보이면 퍼즐 조각 모양 아이콘을 눌러 고정(핀)해두면 편합니다.

> 이후 코드가 수정될 때마다(이 확장은 계속 업데이트되고 있습니다) `chrome://extensions` 화면에서 이 확장의 새로고침(⟳) 버튼을 눌러줘야 최신 코드가 반영됩니다. Forms 탭을 열어둔 채로 새로고침했다면, Forms 탭도 F5로 한 번 새로고침해주세요.

### 4단계. Gemini API 키 등록하기 (AI로 문제를 생성하려면 필요, CSV만 쓴다면 생략 가능)

AI가 문제를 만들어주려면 Google Gemini API 키가 필요합니다. 무료로 발급받을 수 있습니다.

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 접속 (Google 계정 로그인 필요)
2. "API 키 만들기" 버튼을 눌러 키를 발급받고, 표시된 키 문자열을 복사
3. makeForms 확장 아이콘을 우클릭 → "옵션" 선택 (또는 팝업 하단의 "API 키 설정" 링크 클릭)
4. 열린 화면의 입력란에 복사한 키를 붙여넣고 저장

한 번만 등록해두면 됩니다. 이 키는 `chrome.storage.sync`에 저장되어 같은 Google/Microsoft 계정으로 로그인한 다른 기기에도 자동으로 동기화되니, 다른 컴퓨터에서 이 확장을 새로 설치해도 다시 입력할 필요가 없습니다.

> **보안 참고**: 계정 동기화를 거치기 때문에, 그 계정이 로그인된 모든 기기와 계정 자체의 보안 수준에 영향을 받습니다. 공용 컴퓨터거나 계정 보안이 걱정된다면 `extension/*.js`의 `chrome.storage.sync`를 `chrome.storage.local`로 바꿔 기기별로만 저장되게 할 수 있습니다.

## 사용법

팝업(확장 아이콘 클릭 시 뜨는 작은 창) 맨 위에서 두 가지 모드 중 하나를 고릅니다. 문항을 처음부터 AI가 만들어주길 원하면 **"AI로 문제 생성"**, 이미 만들어 둔 문제 목록(CSV 파일)이 있으면 **"CSV 그대로 입력"**을 선택하세요.

두 모드 모두 시작하기 전에 **Microsoft Forms에서 문제를 채워 넣을 폼을 미리 열어두고, 그 탭이 현재 활성 탭이어야** 합니다 (`forms.office.com`의 편집 화면).

### 모드 1: AI로 문제 생성

1. `forms.office.com`에서 편집할 폼을 엽니다. 새 폼이든 기존 폼이든 상관없습니다.
2. 확장 아이콘을 클릭해 팝업을 엽니다. 상단 탭에서 **"AI로 문제 생성"**이 선택되어 있는지 확인합니다.
3. 아래 항목들을 채웁니다.
   - **주제**: 어떤 내용으로 문제를 만들지 간단히 적습니다. 예: `조선시대 역사`, `자바스크립트 기초`, `4칙연산`
   - **파일에서 문제 생성** (선택 사항): 주제를 직접 입력하는 대신, 이미 가지고 있는 학습지나 교재 파일(`.txt`, `.md`, `.pdf`)을 첨부하면 그 내용을 바탕으로 AI가 문제를 만들어줍니다. 파일과 주제를 같이 넣으면 주제는 "이런 식으로 만들어줘" 하는 추가 지시사항으로 쓰입니다. 최대 10MB까지 지원합니다.
   - **문제 개수**: 1~25개 사이에서 정합니다. 한 번에 너무 많이 만들면 시간이 오래 걸리니 처음엔 3~5개로 테스트해보는 걸 추천합니다.
   - **난이도**: 쉬움/보통/어려움 중 선택
   - **문제 유형**: 객관식(4지선다)만 만들지, 단답형도 섞을지 선택
   - **퀴즈 정답 자동 표시**: 켜두면 정답 보기에 자동으로 정답 체크를 해줍니다 (폼이 "퀴즈" 모드일 때만 동작하고, 일반 설문 모드면 자동으로 건너뜁니다).
   - **모든 문제 "필수"로 설정**: 켜두면 생성된 모든 문항에 "답변 필수" 옵션이 자동으로 켜집니다.
   - **모든 문제 점수를 1점으로 설정**: 켜두면 각 문항 하단의 "점수" 입력란(기본값 0)을 1로 자동 입력합니다.
4. 주제나 파일 중 적어도 하나는 반드시 넣어야 버튼이 동작합니다. 다 채웠으면 **"AI로 문제 생성 후 자동 입력"** 버튼을 클릭합니다.
5. 잠시 후(파일이 크거나 문제 개수가 많으면 조금 더 걸립니다) **팝업창이 저절로 닫힙니다** — 오류가 아니라 정상 동작입니다! 문제를 폼에 입력하려면 브라우저가 Forms 페이지에 포커스를 유지해야 해서 일부러 닫는 것입니다.
6. Forms 페이지 오른쪽 위에 어두운색 진행 상황 패널이 뜨고, 문제 제목/보기/정답 체크/저장 여부가 한 줄씩 실시간으로 표시됩니다. **입력이 끝났다는 로그가 뜰 때까지 다른 창이나 탭을 클릭하지 말고 기다려주세요.** (클릭해서 포커스가 다른 곳으로 옮겨가면 입력이 실패할 수 있습니다.)
7. 다 끝나면 패널에 "완료: N개 입력, 0개 실패" 같은 요약이 표시됩니다. 패널 오른쪽 위 ✕를 눌러 닫으면 됩니다.

### 모드 2: CSV 그대로 입력 (AI를 쓰지 않음)

문제를 이미 다 만들어 둔 상태(예: 블루킷용으로 만든 문항 목록)라면, AI 생성 없이 CSV 파일 내용을 그대로 폼에 입력할 수 있습니다. **이 모드는 API 키가 없어도 사용할 수 있습니다.**

1. `forms.office.com`에서 편집할 폼을 엽니다.
2. 확장 아이콘 클릭 → 팝업 상단 탭에서 **"CSV 그대로 입력"** 선택
3. **CSV 파일** 항목에서 파일을 선택합니다. 형식은 **블루킷 게임의 문항 가져오기 템플릿과 동일**합니다 (첫 줄은 제목 줄):
   ```
   Question #,Question Text,Answer 1,Answer 2,Answer 3 (Optional),Answer 4 (Optional),Time Limit (sec),Correct Answer(s)
   1,버섯과 곰팡이 같은 생물을 무엇이라고 하나요?,균류,원생생물,세균,식물,20,1
   ```
   - `Question #`: 문제 번호 (1부터 순서대로)
   - `Question Text`: 문제 내용
   - `Answer 1`~`Answer 4`: 보기 (2~4개, Answer 3/4는 비워도 됩니다)
   - `Time Limit`: Forms에는 이 기능이 없어서 무시됩니다. 열은 있어도 되고 없어도 됩니다.
   - `Correct Answer(s)`: 정답 보기 번호 (1부터 시작). 예를 들어 정답이 Answer 1이면 `1`을 적습니다. 여러 개를 적으면(복수 정답) 첫 번째 번호만 정답으로 표시됩니다.
   - 파일을 선택하면 팝업에 "N개 문항 감지"라고 미리보기가 뜨니, 원하는 파일이 맞는지 확인하세요.
   - 직접 만들어보기 전에 형식이 궁금하다면 저장소에 포함된 예시 파일 [`examples/과학4-1_4단원_다양한생물과우리생활_퀴즈.csv`](examples/과학4-1_4단원_다양한생물과우리생활_퀴즈.csv)를 열어보거나 그대로 첨부해 테스트해볼 수 있습니다.
4. **보기 순서 무작위로 섞기** (기본적으로 켜져 있음): 블루킷 템플릿은 정답이 항상 Answer 1(첫 번째 보기)이라, 이 옵션 없이 그대로 입력하면 모든 문제의 정답이 1번으로 통일되어 학생들이 쉽게 눈치챌 수 있습니다. 이 옵션을 켜두면 문제마다 보기 순서를 무작위로 섞고, 정답 표시도 섞인 이후의 새 위치를 정확히 따라갑니다. 특별한 이유가 없다면 켜둔 채로 두는 걸 권장합니다.
5. "퀴즈 정답 자동 표시", "모든 문제 '필수'로 설정", "모든 문제 점수를 1점으로 설정"은 AI 모드와 동일하게 동작합니다.
6. **"CSV 문항 자동 입력"** 버튼 클릭
7. AI 모드와 마찬가지로 팝업이 자동으로 닫히고 Forms 페이지 위 패널에 진행 상황이 표시됩니다. 문항 수가 많으면(예: 40개) 입력에 몇 분 정도 걸릴 수 있으니 여유를 갖고 기다려주세요.

### 폼 제목은 자동으로 채워집니다

- AI 모드에서는 AI가 주제/자료 내용에 어울리는 제목을 스스로 지어서 폼 제목란에 넣어줍니다.
- CSV 모드에서는 첨부한 CSV 파일 이름(확장자 제외)이 그대로 폼 제목이 됩니다. 예: `과학4-1_4단원_퀴즈.csv` → 폼 제목 "과학4-1_4단원_퀴즈"

### 문제가 생기면

- **입력 도중 오류 로그가 뜨는 경우**: 어느 단계(제목/보기/정답/필수/저장)에서 실패했는지 패널 로그에 정확히 표시되니 그 부분만 수동으로 고치면 됩니다.
- **"Extension context invalidated" 같은 콘솔 오류**: 확장을 방금 새로고침했다면 나올 수 있는 무해한 메시지입니다. Forms 탭을 새로고침(F5)하면 사라집니다.
- **입력이 하나도 안 되고 계속 실패하는 경우**: Microsoft Forms가 UI를 업데이트했을 가능성이 있습니다. 아래 "알려진 제한사항"을 참고하세요.

## 알려진 제한사항

- **선택자(selector)가 깨지기 쉬움**: Microsoft Forms는 공식 확장 API가 없는 내부 UI이므로, 이 확장은 버튼/입력란의 `aria-label` 텍스트 패턴(한국어/영어)이나 `data-automation-id`를 매칭해 DOM을 조작합니다. Microsoft가 UI 문구나 구조를 바꾸면 동작하지 않을 수 있습니다. 이 경우 `extension/page.js` 상단의 `PATTERNS`/`AUTOMATION_IDS` 객체에 새 패턴을 추가하면 됩니다.
- **단답형(텍스트) 문제의 모범 답안은 자동 입력 안 됨**: "새 질문 추가" 클릭 시 뜨는 유형 선택 패널에서 "텍스트"를 선택해 올바른 유형의 카드를 생성하지만, 모범 답안(`answer`) 입력란은 자동으로 채우지 않습니다. 필요하면 수동으로 입력해주세요.
- **정답 자동 표시는 퀴즈 모드에서만 동작**: 일반 설문 폼에는 정답 표시 UI 자체가 없으므로 해당 옵션은 자동으로 건너뜁니다.
- 한 번에 너무 많은 문제(예: 25개)를 생성하면 API 처리 시간과 DOM 조작 시간이 길어질 수 있습니다.

## 파일 구조

```
extension/
├── manifest.json    # MV3 매니페스트
├── background.js    # Gemini API 호출, CSV 문항과의 통합, 오케스트레이션
├── content.js        # 격리 월드 브리지: background <-> page.js 메시지 중계
├── page.js            # 페이지 MAIN world에서 실행되는 실제 DOM 자동화 본체
├── popup.html/js      # 사용자 입력 UI (AI 생성 / CSV 입력 모드, CSV 파서 포함)
└── options.html/js    # API 키 설정
```
